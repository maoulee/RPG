# 作答规则整体审计（2026-08-21）——从人类作答哲学推导 §18 v2

方法论：与 plan 契约 v2 相同——先列"人拿到证据会怎么做"，再把本会话
裁决过的全部答案层失效标本归因到缺失的原则，一次成型，不打地鼠。

## 一、人类作答协议（拿到证据的人怎么交卷）

1. **先问什么答什么**：动笔前重读问题，确认答案类型（谁/哪年/哪里）。
2. **每个判断引证据**：像审计员——每个"通过/不通过"都指向一条具体
   证据（某行某列）；引不出的写"无数据显示"，绝不借用别人的证据。
3. **判别靠扫列**：比大小/最新/最多 = 沿着一列数据扫，不靠记忆。
4. **约束是过滤器不是门**：约束筛掉候选，不推翻已绑定的事实。
5. **只信卷面**：世界知识可以提示假设，但判分依据只能是卷面上的
   证据；卷面没有 → "未知"，不用脑补。
6. **交卷自检**：每个实体对不对类型？每个判断有没有引用？缺证据的
   候选是否标了 UNKNOWN？
7. **部分答案也是答案**：绝不交白卷。

## 三、§18 v2 新增四律（与既有规则合并成完整契约）

- **A 证据引用义务**：CONSTRAINT_CHECK 的每个 PASS/FAIL 必须在括号内
  引用该候选自身的具体显示证据（行/边/单元格）；引不出 = UNKNOWN。
  借用其他候选的证据 = 违规。
- **B 图优先律**：世界知识可提出假设，判决只能来自显示证据；图缺
  判定边 → UNKNOWN（JoJo：English 的语族边其实在场，走图同样判
  PASS——此律的价值是把 gold 错配透明化而非静默脑补）。
- **C 判别可见律（显示侧共责）**：latest/largest/most 类判别属性必须
  以可扫读的列呈现（记录表/连接表）；判别失败同时是显示失败。
- **D 归因到候选**：证据属于它点名的候选；每候选每约束独立判定
  （Drew Brees 的 Stanford）。

## 四、新展示形式对归因的结构性增益（回答"推理是否会更好"）

会，且是结构性而非概率性——因为**引用义务需要可寻址的证据单元**：

| 旧形态 | 新形态 | 归因增益 |
|---|---|---|
| 8k-token 单行 CVT 串 | 记录表（行=事件，列=属性） | PASS 可引"某行某列"；判别=扫列（Kim netflix 直接按列比大小） |
| 跨行重复的关系散边 | 连接表（键列+扇出列） | 交集=列对齐（Faroese：languages 列 vs country 列同屏可比；main_country 成列） |
| candidates 混在证据里 | 导航索引独立 | "哪里能走"与"什么是真"分离，证据区零导航噪声 |
| 命名跳数无上限的散边行 | ≤2 跳模式路径分块 | 每块头部声明回答哪个 fact 的哪个槽位 |

量化依据：ANSWER-MISS 245 例中 98% gold 在场——不是没看见，是**淹没**。
L1/L2/L3 三律 + 表格形态把淹没层直接移除；引用义务让每步判定有落点。

## 1. 问题设定

**任务**。多轮知识图谱问答（KGQA）智能体。一条轨迹的结构：

1. **规划/分解**：把问题拆成若干子查询（每个子查询对应一个待验证的事实片段）；
2. **逐子查询检索**：每个子查询通常产生两个动作——先**选关系**（从语义检索给出的候选
   关系里挑），再**走查取证据**（沿选定关系在图上走，取回一个小的三元组集合）。一次走查
   的产物称为一个**子图**；
3. **作答**：一个 `answer` 动作输出实体列表。

**可观测奖励**。只有轨迹级 F1（预测实体 vs 金标实体集合，模糊字符串匹配）。没有任何
轮级标注。这是纯粹的"稀疏结果奖励、稠密行为序列"的信用分配问题。

**训练组织**。同一问题用温度采样生成 G=8 条轨迹构成一个**组**（组内共享问题与金标，
行为各异）；离线强化（数学上等价于带符号的加权模仿学习，§7）需要为**每一轮**动作分配
一个优势值 a_t。

**信用分配的三条设计目标**（各来自早期失败教训）：

- (a) **行为–结果解耦**：同样的探索行为应得到同样的探索信用，不因该轨迹最终答案的
  运气而涨落。（旧耦合方案中 95% 的"探索正确但答错"轨迹被错误压制；答案轮吸走了
  赢家轨迹 93.9% 的信用。）
- (b) **有效性甄别**：关键探索拿满，冗余探索零/负信用，有害探索受抑。
- (c) **无稀释**：每轮信用不随轮数摊薄——做了四件有价值的事，就应该各拿各的，不除以 4。

**关键经验事实**（整个设计的实证起点）：轨迹的**证据质量与最终结果奖励的相关性仅
0.10**。结果奖励几乎教不了探索行为；探索的价值必须另行测量。

## 2. 记号

一条轨迹内的对象：

- 子图 i ∈ {1..k}：第 i 次成功走查带回的三元组集合（按轨迹内出现顺序编号）；
- **锚实体**：问题文本中出现的实体，检索的起点；
- 金标（gold）：标准答案实体集合；证据：k 个子图的并；
- 轮 t：一个 assistant 回复。一个子图通常对应两轮（选关系、走查），**两轮共享该子图
  的判定结果**（见 §6）。

四个测量概率（由冻结的基座模型作为"读者"测出，构造见 §4.1）：

| 符号 | 含义 |
|---|---|
| p0 | P(gold \| 仅问题，无证据) —— 先验 |
| pF | P(gold \| 全部证据) |
| p_i^alone | P(gold \| 仅子图 i 的证据) |
| p^−i | P(gold \| 去掉子图 i 后的其余证据) |

由概率差分派生的**轮级信号**：

| 符号 | 名称 | 定义 | 直觉 |
|---|---|---|---|
| f_i | 前向独立值 | p_i^alone − p0 | 它**单独**带来多少答案信息 |
| l_i | 留一伤害 | pF − p^−i | **拿掉**它损失多少（leave-one-out） |
| d_i | 顺序增量 | P(gold\|前 i 个) − P(gold\|前 i−1 个) | 按轨迹**实际加入顺序**的边际贡献 |
| g_i | 金标首达 | 该子图**首次**带入证据的金标实体占比（按轨迹顺序认领，后来的不计） | 谁真正把答案实体挖了出来 |

组级量（§5）：R_exp（证据召回）、A_exp（探索优势）、A_ans（答案优势）、S（尺度锚）。

## 3. 总览：两轴记账，四层流水

```
测量层   冻结读者概率 (p0/pF/f/l/d) + 金标首达 g + 图结构测试     §4
轨迹层   组内差分 → A_exp 与 A_ans（门控 z-score，尺度锚 S）      §5
轮层     三层判定级联 → 每轮类别 → 离散权重 × A_exp                §6   ← 核心
梯度层   每轮优势均匀落在该轮回复的全部 token 上                   §7
```

**两轴记账**：除作答外的所有轮（规划、选关系、走查）只消费**探索轴**优势 A_exp；
作答轮只消费**答案轴**优势 A_ans。两条轴永不交叉——答案的好坏不改探索轮的信用，
证据的丰欠不改作答轮的信用。这是目标 (a) 的构造性实现（相同行为必然得到相同信用，
因为探索信用只依赖证据内容与组内对比，不依赖本轨迹的 F1）。

## 4. 测量层：信号从哪里来

### 4.1 概率测量：冻结的基座模型当"读者"

把"给定某份证据，这个问题的答案应该是什么"的判断交给**冻结的、未训练的基座模型**：
构造提示词 `问题 + 证据文本`，teacher-forcing 金标答案串，读取模型对它的指派概率。
对多实体金标，逐实体分别测概率再取算术平均（实体数封顶 8，确定性抽样），避免长列表
联合概率被系统性压低。所有 f/l/d 信号都是这些概率的差分。

**测量的已知病理**（决定了概率信号只能相对使用，不能做绝对价值基线）：

1. 精确 token 似然读不出模糊匹配的正确性——金标换同义词、部分列表，人类评分算对，
   似然读作错。实测 corr(pF, 真实 F1) ≈ 0.03。曾用 pF 做答案轴的价值基线（F1 − pF），
   76% 的样本被系统性多记 credit，已否决。
2. **读者端候选竞争**：证据里金标与干扰实体并列时，概率质量被分摊——一个**携带金标**
   的子图加进来，pF 反而可能下降。实测 46% 被概率标记为"有害"的子图其实是携带金标的
   判别性检索。这直接导致 §6 有害判定的"金标否决"条款。
3. 单子图轨迹与多子图轨迹的历史数据概率域不一致（对数域 vs 概率域），因此单子图轨迹
   不做级联判定，走二值兜底门（§6.4）。

### 4.2 金标首达 g_i

按轨迹内子图出现顺序扫描，每个金标实体由**第一个**把它带进证据的子图认领。g_i =
该子图认领的金标占比。它测"执行时刻的可见产出"，与概率测量独立（约束型子查询——
不含金标实体但缩小解空间——对 g 不可见，对概率可见；反之金标实体被携带但概率饱和
时，g 仍能指出谁带来的）。

### 4.3 结构测量（当前全部为**二值/硬**判定）

把 k 个子图的三元组边并成一张无向图，从锚实体出发做广度优先可达性：

- **不可缺**（indispensable）：去掉子图 i 后，从锚可达的金标实体数下降 → i 不可缺。
  （注意这是"锚→金标可达性"测试，不是多跳路径完整性测试。）
- **台阶性**（lineage）：后续某次检索的中心实体来自子图 i 的证据 → i 是垫脚石
  （中间跳，自己不带金标但链路经过它）。
- **关系重叠率**：子图 i 检索的关系名集合中，与**先前子图已检索过**的关系之占比。
  用于裁决"互补 vs 重复"（§6 第 3 层）——这是唯一能区分二者的信号，因为概率测量
  无法区分（一份拷贝的单独值 ≈ 原件的单独值）。

### 4.4 测量的盲区互补表（为什么需要这么多信号）

| 信号 | 测什么 | 盲区 |
|---|---|---|
| 留一 l_i | 移除的伤害（必要性） | **替代冗余下全零**：多个子图互为备份时，谁的单独特移都不疼。实测 58% 的金标携带子图被 l 掩蔽 |
| 前向 f_i | 执行时刻的独立信息 | 分不清互补与重复（拷贝的 f ≈ 原件的 f） |
| 首达 g_i | 谁把金标带进来的 | 看不见约束型步骤（不含金标实体） |
| 顺序增量 d_i | 实际加入顺序下的边际 | 位置依赖（同一子图先加后加值不同）；被前面兄弟的充分性掩蔽 |
| 结构测试 | 连接结构的承担 | 目前是硬判定，无程度；且只看可达性，不看路径份额 |

被 l 掩蔽的步骤中 84% 靠 f 恢复——这就是级联里 f/g/结构必须与 l 并存的原因。

## 5. 轨迹层：组内差分与尺度

**探索轴**。轨迹级探索奖励：

- R_exp = |金标 ∩ 证据| / |金标|（模糊匹配；来自结构化字段，含渲染截断的隐藏部分）；
  当新 harness 下证据可见性在组内饱和（全组召回=1，无区分度）时，改用教师强制增益
  pF − p0。

组内（同问题的 8 条轨迹）中心化得 A_exp；**门控 z-score**（v12.1）：

- 组"存活"（alive，组内最大 R_exp 增益 > 0.05，约 62% 的组）→ A_exp = z-score 截断
  在 ±1——赢家的有效轮拿满 ±1.0；
- 组"死亡"（全组增益≈0，测量噪声主导）→ 只做原始中心化，不放大噪声；
- **充分性不足**惩罚：pF − p0 ≤ 0（检索对答案概率毫无帮助）→ A_exp 再减 δ_abs。
  31% 的组曾整组"欠检索"却在纯组内差分下逃逸，此条款堵这个洞。

**答案轴**。f_ans = F1(预测实体, 金标 ∩ 证据)——**只对证据可达的金标语料记分**；
金标 ∩ 证据 = ∅ 时 f_ans = 0（无证据支撑的正确答案是运气，不强化；实测 2% 轨迹）。
组内中心化 + 同样的门控 z（答案组存活条件：组内 F1 标准差 > 0.1，约 44%——56% 的组
全对，中心化后天然≈0，不放大）。

**尺度锚 S** = 全体组内 R_exp 极差的中位数（"一个典型组间差异"有多大）。所有绝对
惩罚量（δ_abs 等）自动取 S 的倍数（0.5S 等）。教训：手设常数曾是组间差分信号的
5–10 倍，直接压没了学习信号。

**答案轴基线的选择**：用过冻结模型 pF 当价值基线（a_ans = F1 − pF），因 §4.1 病理 1
（corr≈0.03）噪声主导而否决，退回组均值——组均值是蒙特卡洛价值估计，8 条兄弟轨迹
就是 8 个对照样本。

## 6. 轮层：三层判定级联（核心——"我们目前究竟怎么判定"）

对轨迹中每个子图 i（其选关系轮与走查轮**都**领取该子图的判定结果），按**确定性优先、
逐层短路**的级联分类。设计哲学：结构事实（确定性、不可辩驳）先裁决；概率测量（带噪
声）只在结构沉默时裁决；新颖性（行为层面）最后裁决。

```
第 1 层  结构（硬）
   不可缺（去掉它锚→金标可达性受损） 或 台阶性（后续检索以它为跳板）
   → 类别 = 有效（indispensable）
第 2 层  概率
   有害 ⟸ 三个条件同时成立（缺一不可）：
      d_i < −τ （加入时确实让答案概率下降）
      ∧ g_i = 0 （没有首达任何金标 —— 金标否决，挡掉读者端候选竞争的 46% 假阳性）
      ∧ f_i ≤ τ （无任何独立信息 —— 在路径上的泛洪检索若 f>0，降级为冗余而非有害）
   有效 ⟸ d_i > τ 或 l_i > τ （加入时有增量，或移除时有伤害）
第 3 层  新颖性（d、l 全平坦但 f_i > τ：携带独立信息却在上下文中无增益）
   关系重叠率 ≥ 0.5 → 重复检索（拷贝）→ 类别 = 冗余
   关系重叠率 < 0.5 → 互补子句（独立约束被兄弟掩蔽）→ 类别 = 部分有效
否则（所有信号平坦）→ 类别 = 冗余
```

其中 τ ≈ 0.005（概率域小阈值）。经验依据：第 3 层的模糊类占多子图轨迹的 15%
（535 个子图），关系重叠把其中 71% 判为互补、21% 判为重复——**概率不可分、结构可分**，
这是级联里结构先行的原因。

**类别 → 权重**（v12 离散有效性矩阵，按轨迹极性分栏；A_exp 为该轨迹的探索轴优势）：

| 类别 | 正轨迹（A_exp > 0） | 负轨迹（A_exp < 0） |
|---|---|---|
| 有效 | +1.0 × A_exp（吃满） | 0 |
| 部分有效 | +0.5 × A_exp | 0 |
| 冗余 | −0.5 × \|A_exp\| | 全额 A_exp（吃满负值） |
| 有害 | −0.5 × \|A_exp\| | 全额 A_exp |

要点与理由：

- **负轨迹中有效/部分有效轮记 0，不记正也不记负**：同一行为在批内其他赢家轨迹里已
  拿满正信用（跨轨迹聚合）；失败轨迹中的正确步骤不该被连坐。反之，**失败轨迹中的
  冗余/有害吃满负值**——浪费本身就是失败的一部分。
- 实现中冗余与有害的权重相同（−0.5 与全额），类别区分目前只起诊断作用。
- **规划/分解轮**：设计意图是 `scale = 1{R_exp > 0}` × A_exp（规划连贯且探索触达金标
  才给）。**实现缺陷见 §9.1**。
- **无作答轨迹**（轮数耗尽）：答案轴的 A_ans 追加到最后一轮上，惩罚不会被静默丢弃。
- **无守恒约束**：Σ_t a_t 不必等于任何轨迹级量；轮内不除以轮数（目标 (c)）。曾用
  "守恒分配"（信息块 vs 答案块两层按责任比例切分 Σa = A_k），因稀释与耦合问题废弃
  （§8）。

### 6.4 单子图/无顺序测量轨迹的兜底

只有 1 个子图（或历史数据缺顺序测量）时走二值门：g_i > 0 ∨ f_i > 0.01 ∨ l_i > 0.01
→ 有效，否则冗余。单子图没有联盟结构可分析，LOO/前向退化，二值门足够。

## 7. 梯度层：轮级信用如何进入训练

第 k 轮 assistant 回复的**全部 token 均匀携带** a_k；损失是逐 token 加权对数似然
（带符号）：L = −Σ_t a_t · logπ(y_t) / |completion tokens|。a>0 抬升该轮回复的概率，
a<0 压低，a=0 零梯度。数学上等价于 β=0、无参考模型的离线 GRPO——标量 GRPO 把
Σa_t 求和成一个数（轮结构坍缩为轨迹标量），本方案保留逐轮 a_t，使轮级信用真正到达
梯度。逐 token 归一化天然抗回复长度膨胀。

**诚实的现状**（讨论前须知）：该信用机制在**数据侧**已验证（99% 的组内存在轮级
模式差异；解耦修复了 95% 的错误压制），但在 9B + LoRA + 1 epoch 的训练规模上，
标量/逐轮两种形态对终局 F1 均为持平（3-seed，±3pp 检测下限）。已证明的杠杆是数据
修补（+3pp）与 harness 修复（+3pp）。因此本讨论的价值定位在**机制层**——为下一轮
实验准备好正确的判定语义，而非立即换训练算法。

## 8. 演化中被否决的方案（避免讨论重走弯路）

| 被否决方案 | 否决原因（实证） |
|---|---|
| 结果优势直接乘到每轮（耦合 imp×A） | 相同探索因答案运气得不同信用；95% 好探索+坏答案被错误压制 |
| 守恒分配（Σa_t = A_k，按信息/答案两块责任比例切分，块内再按 LOO 比例分） | 稀释（÷轮数）；冗余互相备份时 LOO 全零导致预算均分给无效轮；答案轮/探索轮耦合 |
| 冻结模型 pF 作绝对价值基线 | corr(pF, F1)≈0.03，噪声主导，76% 系统性多记 |
| 步间差分 ΔΦ 直接当轮信用 | 概率尺度畸变（0.01→0.10 与 0.90→0.99 不等价）+ 路径依赖 |
| 手设绝对惩罚常数（冗余罚 0.08 等） | 是组间差分的 5–10 倍，压没学习信号；改为尺度锚 S 的倍数 |
| 加性过程优势（在 A_exp 上加顺序增量项） | 为保持两轴纯性而撤回；离散权重胜出 |

## 9. 已知缺陷（实现级，2026-08-18 实证确认）

### 9.1 规划轮身份泄漏（影响所有 v12/v12.1/v14 数据）

级联实现中，规划/分解轮没有被单独分支处理：判定变量沿用上一循环遗留的值——恒等于
**最后一个子图**的身份。后果：规划轮领取的是**最后一个子图**的级联类别，而非自己的
规划规则。最小复现（赢家轨迹，A_exp=+1，末子图冗余）：规划轮得 −0.5（继承冗余类），
而设计意图应为 +1.0（R_exp>0）。`scale = 1{R_exp>0}` 一行成了死代码（仅统计）。
**任何 v12 系训练数据中规划轮的信用分布都不可信**；末子图为冗余/有害的轨迹里规划轮
被系统性错误惩罚，末子图为有效的轨迹里规划轮侥幸正确。

### 9.2 冗余类权重与记录不符

## 10. 开放设计空间：软化 S_t、N/U/S 融合、结构条件化 Shapley

本节把"现状中所有硬的判定"列出，并给出下一步讨论的锚点。**现状中尚无任何 soft
结构分**——结构信号目前只有二值的不可缺/台阶/重叠率三支点。

### 10.1 现状中的"硬"判定清单（软化候选）

| 硬判定 | 现值 | 软化候选 |
|---|---|---|
| 不可缺 | {0,1}（可达金标数是否下降） | 去掉 i 后**可达金标数/路径质量**的相对下降幅度；或锚→金标路径覆盖份额 |
| 台阶性 | {0,1} | 以 i 为跳板的后续检索数/后续检索总数（归一）；或台阶链加权和 |
| 类别 | {有效, 部分有效, 冗余, 有害} 四离散类 | 连续有效性分 v_t ∈ [0,1] + 离散惩罚只保留行为层（重复检索罚） |
| 权重 | {+1.0, +0.5, −0.5, −0.5} 固定倍数 | w(N,U,S) 的融合函数 |
| 关系重叠门 | 0.5 阈值二分 | 重叠率本身作连续特征 |

### 10.2 三族信号的自然命名（N/U/S）

- **N（必要性，necessity）**：l_i（留一伤害）与不可缺性——"拿掉它行不行"。测联盟
  对成员的依赖。
- **U（有用性，usefulness）**：f_i（前向独立值）与 g_i（金标首达）——"它自己带来了
  什么"。测成员单独的产出。
- **S（结构贡献，structure）**：软化后的结构量 S_t ∈ [0,1]——"它在证据图的连接结构
  中承担多大份额"（路径覆盖、可达性承担、台阶支撑）。

现状的级联 ≈ 硬版 `w = 1{N ∨ U ∨ S}`，其中 N、S 各自只有二值支点。

### 10.3 融合函数必须保持的不变量（约束，不是选项）

1. G1 行为–结果解耦：w 只能消费轨迹内测量与组内对比，不得消费本轨迹 F1；
2. G2 答案归因：答案轴独立；
3. G3 轴零耦合；
4. 无稀释：w_t 不随 k（子图数）衰减；同行为同信用（w 对相同测量取相同值）;
5. 尺度锚定：融合输出进入 a_t = w_t × A_exp 后，其量级必须与尺度锚 S 的组间差分
   相称（手设常数压过差分信号的教训）；
6. 概率域输入（N、U）只能相对使用（z 域/分位域融合，不叠原始概率，因 §4.1 病理）。

### 10.4 替代冗余问题与 Shapley 的形式化对接

**问题重述**。定义证据子集上的价值函数 v(S) = P(gold | ∪_{i∈S} 子图_i) − p0。现状
测的是 v(N) − v(N∖{i})（留一）与 v({i})（前向）与一个插入序的边际 d_i。若 i、j 互为
替代（信息重叠），则两者留一都≈0——"无用"与"被备份"不可分；更糟的是重叠备份对会
互相把对方的留一推成负值（移除反而升概率，读者端竞争），实测 41% 的多子图轨迹出现。
这正是"多个子图互相替代导致 leave-one-out 接近 0"。

**Shapley 为什么天然解决**。φ_i 对所有插入位置平均边际贡献：(i) **效率公理**
Σφ_i = v(N)——联盟总增益被恰好分完；(ii) **对称公理**——两个信息等价的子图各分一半，
而不是双双为零；(iii) 单调——备份对的总贡献被承认，且**多一份备份不再增加总价值**
时自动体现边际递减。留一只测了 v(N)−v(N∖{i}) 这一个反事实；Shapley 把整个联盟格上的
反事实都平均进来。

**结构条件化的两个正交读法**（可同时成立）：

1. **条件化联盟空间**：不是所有子集都是合法证据组合——只有保持锚→金标连通的子集
   才有非零价值（v(S)=0 若 S 断连）。把博弈定义在结构合法的子集族上，采样/求和只在
   该族内进行。这同时压掉 2^k 组合爆炸（结构上无意义的组合不评估）。
2. **价值函数本身就是结构博弈**：把 v 定义为路径覆盖博弈——v(S) = Σ_{路径 π}
   w(π)·1[π 的边全部 ∈ S]，则 **S_t 的自然定义就是覆盖博弈的 Shapley 值**：子图 t 在
   随机插入序下期望承担的"新覆盖路径份额"。这个读法把"软化结构分"与"结构条件化
   Shapley"统一成同一件事：S_t = 覆盖博弈的 Shapley 值。

### 10.5 一个必须先回答的张力（效率公理 vs 反冗余教学）

纯 Shapley（效率+对称）会给一份**完全重复的拷贝**记一半信用——信息论上没错（它确实
承担了一半覆盖），但行为教学上当前方案明确要惩罚重复检索（ fetching 已有信息是浪费
轮次与上下文预算的行为）。也就是说：**Shapley 度量信息贡献，训练目标要定价行为**。
融合时二选一或分层：

- 分层：信息轴用 Shapley（N、S 同为不同博弈的 Shapley 值），行为轴保留显式的重复
  检索罚（关系重叠率连续化）；
- 或条件化：把边际定义在"给定当前前缀"上——这正是现状 d_i 的语义（插入位条件
  Shapley），拷贝的前缀条件边际恰为 0，天然反冗余，但失去效率公理（Σd_i = v(N) 仅在
  该固定序下成立）。

这个选择决定整个融合函数的形状，建议作为讨论的第一议题。

### 10.6 计算成本与可复用资产

- 现状每条轨迹的测量代价 ≈ 金标实体数 × (1 + 3k) 次 teacher-forcing 评分（k=子图数，
  实测 0.07 s/轨迹）。**精确 Shapley 需 2^k 个子集评估**：k≤4 时约 16×8=128 次/轨迹，
  与现状同量级，**可直接精确算**；k>4 需采样或结构条件化截断。
- **组内 8 条轨迹是天然的联盟样本**：同问题的兄弟轨迹各自检索了不同的子图组合与
  顺序，其 pF 已全部落盘。把各轨迹的证据集合按关系指纹对齐后，可用成员指示变量回归
  v(S_j)（回归式 Shapley 估计），**零额外 GPU 成本**。跨轨迹子图对齐是实现上的主要
  工作量（关系集合指纹匹配，非 id 匹配）。
- d_i（顺序增量）本身就是一个采样排列下的 Shapley 边际样本；现有 Vseq 数据可复用为
  单排列基线。

### 10.7 建议的讨论议题顺序

1. §10.5 的张力先裁决（效率公理 vs 反冗余）——它决定融合函数的形状；
2. S_t 的定义选型：覆盖博弈 Shapley vs 可达性相对下降 vs 台阶归一计数；
3. N/U/S 融合：max / noisy-OR / 分层（S 定支撑、N 定量级、U 定兜底）/ 双 Shapley + 
   singleton 三币种;
4. 负轨迹极性策略在连续权重下如何推广（现状的 0/全额二分是离散类的配套）；
5. 验证准则：现状 §6 的判定在多大比例案例上被 soft 版改变（回归测试集可从 v10.5 的
   单元格计数 10842/1838/4345/15413 重建）。

### 10.8 收敛裁定（2026-08-18，外部讨论后定稿）+ v1.5 实测

**裁定**（详见 §10.5–§10.6 的张力裁决）：

1. **N 只算展示层三元组**。展示层的合并/截断/压缩本身就是预算约束，"灌水换 N"构造
   不出来；且与 U 的测量口径（证据文本截 15 行）天然一致。实现承诺：N 永不用
   ctx 级结构化字段（那是召回率口径）。分支引用行需展开一次再计 N。
2. **替代问题通过"证据从边际换独立"解决，Shapley 撤出**。d/l 平坦时改用
   N（新信息）∧ U（单独作答增益）判定，金标首达 g 作 OR 臂（U 的精确 token 匹配
   读不出近似表述，g 是零成本保险）。该判定**与检索顺序无关**——比边际/联盟系方案
   更贴合 G1"同行为同信用"。替代对被有意判有效（各自都是一份有效证据）；反重复只
   打"什么都没带来"（N≈0）与"带来但无效"（N>0∧U≈0）两档。
3. **v1.5 级联**（在 §6 三层结构上改三处）：

```
L1 结构（不变）: 不可缺 ∨ 台阶 → 有效
L2 概率（不变）: 有害 = d<−τ ∧ g=0 ∧ f≤τ；有效 = d>τ ∨ l>τ
L3 新颖性（改）: d,l 平坦时
    g>0 ∨ (N≥0.2 ∧ f>0.005) → 有效（满额；旧为 partial 0.5）
    N<0.2                    → 冗余-重复（真拷贝）
    N≥0.2 ∧ f≤0.005          → 冗余-无关（新增无效信息）
规划轮（修）:   scale = 1{R_exp>0} × A_exp（修复身份泄漏）
失败轨迹（新）: 展示层未见金标 ∧ 与成功兄弟轨迹的 (中心,关系集) 结构相似度≥0.5
               的冗余/有害轮 → 保护记 0（参考集保护）
```

**实测**（`scripts/recompute_advantage_v15.py`，同一数据新旧对比，轨迹层量复用
存储值使差异纯来自轮层规则；v12 复制率 94.7% / v14 94.0%）：

|---|---|---|
| 级联轮类别：有效 | 5196 → 7097 (+37%) | 782 → 1112 (+42%) |
| partial（半额） | 1497 → 0（并入满额） | 217 → 0 |
| 冗余-重复 | 672 → **0** | 169 → **0** |
| 冗余-无关（新类） | 268 | 54 |

| 轨迹 \|Σa\| 中位 | 0.500 → 0.647 | 1.000 → 1.010 |

**关键判读**：

1. **旧"重复"类是关系命名伪影，不是内容重复**。672 轮旧判重复中，按内容计
   N≥0.2 的占 100%——没有一例是同中心同关系的真拷贝重取。202 轮有新内容且有
   独立价值（如 Nolan Ryan 案：关系集完全重叠 ov=1.0，但 65% 新边、独立值 0.254
   ——一次扩中心的再检索，旧规则罚、新规则救回）；268 轮有新内容但无独立价值
   （真噪音，维持负信用）。旧规则的关系重叠门系统性地把"换实例的同类检索"误判
   为拷贝。
2. **规划轮泄漏主导了 v12/v14 数据的规划轮信用**：2/3 的规划轮信用改变、
   1000+ 轮由负转非负。旧数据的规划轮信号基本不可用（§9.1 的量化确认）。
3. **参考集保护真实但极稀有**（0.1–0.3%）：失败轨迹大多走的是真正不同的（错误）

   角色中心 + portrayed_in_films 正是该问题的正确第一跳，旧罚 −1.03，新保护）。

4. **信用总量稳定**：|Σ| 中位与均值几乎不动——重分配主要发生在轨迹内部（重复

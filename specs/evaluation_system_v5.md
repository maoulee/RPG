## 一、理念公理（用户陈述，2026-09-17/18）

A1 评价对象 = **单个行为块对概率的影响**；行为评估与答案对错脱钩
   ——证据概率（pF 等）是独立的检索概率优势（检索赢答案输是正检索信号）。
A2 三方法分工：证据概率答"当下有效性"；反事实答"早期模块归因"
   （首现归属——同信息归首次交付者）；结构优先答"必要性"
   （结构判定不需要概率）。
A3 语境路径 = **declared step 关系链本身**。检索关系全部经由 step
   提交，层链（anchor_sequence）已实例化为符合语境的路径——
   不需要另外的语义过滤层；harness 判定"模式路径是否命中答案"即可。
A4 树架构语义：每个子图行为 = 对关系层的更新（extend/update），
   层链即 step 关系序列——这是断链定位（L6）的结构基础。
A5 冗余 ≠ 无关：**冗余** = 之前的块已检索到对应内容但模型重复探索；
   **无关** = 探索到答案无关信息但未误导推理（无害）。
A6 互补判定（Q1 裁定）：**分类用联合测试，信贷对半分**——
   joint − max(single) > 噪声底(0.03–0.05) ⇒ 互补均有效；
   每方信贷 = ½ 独立价值 + ½ 联合增量（n=2 恒等式，SM:7173）。
   这修订 §10.8 的替代对满额裁定。
A7 断链定位（步级，非 case 级）：将最佳路径的 step 关系与断链路径的
   关系**序列对齐**，判定**哪一步**导致错误（见 L6）。

## 二、七层判定流程

```
L0 语境路径命中（harness 结构判定）
    每个行为块的 declared 层链 = 语境路径（A3，无需语义过滤）
    走链得完成集，判定 完成集 ∩ {gold | 绑定答案域} ≠ ∅
    命中 → 该通路 reached，入 L1
    未命中 → 通路 unreached，其块入 L5/L6
L1 必要性（反事实结构，已连通通路内）
    移除块的首现边 → 该通路内部 锚→gold 断 ⇒ necessary
    概率不参与（A2）；首现归属保证跨块同信息不重复记账
L2 互补（多条 reached 通路之间，联合测试）
    p_joint − max(p_single) > 噪声底 ⇒ 两条通路互补均有效
      （complementary；信贷 = ½ p_alone + ½ 联合增量）
    p_joint ≈ max(p_single) ⇒ 完全重复 → 双方入 L4
    单通路 case 跳过本层
L3 概率有效（通路内部，块级）
    d > τ 或 l > τ ⇒ effective-prob
    早期模块由 l 救（反事实归因，A2）；τ=0.005 概率域
L4 冗余（重复检索，A5 前半）
    与已服务调用同 resolved 关系集 / 核心路径相似 且 N 低 ⇒ redundant
    （resolved 键 = 名字解析后的 (center-set, short-rel-set)——
     表面变体不再绕过；_sg_served 的教训）
L5 无关-无害（A5 后半）
    未连通 + 与已连通路径无重叠 + 无概率损伤（l ≥ −τ）
    ⇒ irrelevant-harmless（不罚不计功）
L6 断链定位（unreached 通路，关系序列对齐，A4/A7）
    对齐对象：最佳路径层链（逐跳关系集）vs 断链路径层链
    对齐方式：逐跳比较（跳内关系集交集/等价），最长公共前缀
    → 第一个分歧层 = break-point：
      该步的关系更新使路径脱离答案
    块标记附带 {分歧层号, 该层提交的关系, 最佳路径同层的关系}
    ——错误类型可直接读出（选错方向 / 选了反向关系 / 多余跳）
```

判定顺序：L0 分流 → reached 通路走 L1→L2→L3→L4；
unreached 通路走 L6（break-point 块）+ L5（break-point 之前/之外的
无害块——它们曾走在可对齐方向上或至少未误导）。

### 最佳路径（对齐基准）的三来源，按优先级

1. **本轨迹的 reached 通路层链**（declared 语境链，A3）；
2. **oracle 链**：全轨迹无连通（1379 型）时，取 case 图上
   锚→gold 的 declared 语义最短链（评估侧 gold 已知；oracle 只服务
   对齐诊断，不进档位判定——展示基准约束档位，不约束诊断参照）；
3. **成功兄弟轨迹的层链**（2784 s0 成功 / s2 失败型）作辅助。

| 粒度 | 标记 | 语义 |
|---|---|---|
| 块 | necessary | 移除断路（通路内反事实） |
| 块 | complementary | 联合测试命中，互补有效 |

## 五、理念仍判不了的边界 case（如实记录，待后续裁定）

1. 含金噪声块（567-[5]：文本含 gold、三概率信号负）——L1 可能必要
   而 L3 概率负；需要复合限定符而非单档。
2. 空交付块（1731 mod0：交付空、l 最高）——"此路不通"的否定信息
   无层认领；候选：并入 L4 语义（对假设空间的查重）或新设 dead-end-info。
3. 概率倒挂（2209：p0=.61 → pF=.095，多 gold 竞争）——L3 的 d 读数
   在多 gold 串上失真（per-entity 已部分缓解）。
4. 记忆天花板（p0 高）——概率轴惰性，联合测试也惰性。
5. 部分重叠通路——joint−max 落在噪声底上的情形，L2 与 L4 边界模糊；
   候选：结构判据（两通路核心路径的边不相交度）。
